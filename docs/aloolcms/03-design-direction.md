# AloolCMS — Design Direction

**Grounded in:** ADI collection observations + AloolCMS product thesis  
**Not grounded in:** Freestanding taste without evidence

## Design read

**B2B editorial infrastructure console** for agency editors/operators — a research-grade instrument more than a SaaS marketing app. Personality: quiet, literate, precise.

Dials: variance **5** · motion **3–4** · density **6–7**

## North star

> AloolCMS should feel like a well-kept publishing instrument: grouped navigation, medium-density catalogues, a paired composer/preview, one accent, and typography that carries authority — recognizable without the logo.

## Principles (evidence-linked)

1. **Index over moodboard** — type, rules, and status carry hierarchy (Pentagram / HF / ADI archive philosophy).
2. **Grouped rail + jump** — Grouped Sidebar Sections + Keyboard Shortcut Hint.
3. **One accent** — Single Accent Colour; coral may remain or be replaced but multiplicity is out.
4. **Rules, not shadows** — Bordered Panels / Rule Separated Sections; hairlines over soft elevation.
5. **Paired composition** — Code Panel Pairing / Retool dual surface → page editor + preview.
6. **Medium density** — default; high density only for power tables.
7. **Translate, don’t paste** — marketing traits (signup header, announcement bar, full-bleed hero) stay outside admin.
8. **Theme humility** — product chrome ≠ client theme; public themes express clients.

## Shell recommendation (baseline for explorations to challenge)

| Region | Direction |
|---|---|
| Primary nav | Grouped left sidebar (Site · Pages · Content · Library · System) |
| Global find | Header search + ⌘K affordance |
| Stage | Light / paper |
| Brand slab | Optional dark shell (already shipped) — keep or unify per concept |
| Titles | Display scale / mixed serif-sans for page titles only |
| Meta | Mono for status, IDs, times; uppercase eyebrows for kickers |
| Primary action | One filled control (New / Publish) — not coral spam |

## Experience priorities

1. Desk / work queue (modified, drafts, broken refs, submissions)
2. Page composer as hero product surface
3. Collection lists that stay orienting despite sameness
4. Empty / loading / error language as identity
5. Reserve chrome for future site switcher + roles
