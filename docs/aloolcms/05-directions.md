# AloolCMS — Five Design Directions (ADI-grounded)

Each direction differs in hierarchy, nav model, interaction model, density, and storytelling — not only palette/font.  
Prototypes (live, multi-screen): [http://127.0.0.1:5173/concepts/aloolcms](http://127.0.0.1:5173/concepts/aloolcms) · code in `apps/web/src/concepts/aloolcms/`

Evidence keys used throughout: Grouped Sidebar, Keyboard Shortcut, Single Accent, Mixed Serif/Sans, Bordered Panels, Code Panel Pairing, Medium/High Density, Dark Shell Light Body, Archive IA.

---

## D1 — Folio Shell
**Evolve Editorial Console with ADI docs-shell discipline**

| Axis | Choice |
|---|---|
| Nav | Grouped left rail (Site · Pages · Content · Library · System) |
| Hierarchy | Eyebrow → serif title → work desk |
| Interaction | Desk queue primary; ⌘K secondary |
| Density | Medium |
| Story | “What needs an editor” |
| Identity | Paper + dark shell + coral accent + Instrument/Geist |

**Evidence:** Grouped Sidebar, Medium Density, Mixed Serif And Sans, Dark Shell Light Body, Uppercase Eyebrow  
**Prototype:** `concepts/d1-folio-shell.html`

---

## D2 — Spec Instrument
**Dark power-user console; command-first**

| Axis | Choice |
|---|---|
| Nav | Narrow icon rail + command strip |
| Hierarchy | Signals → surface → inspector |
| Interaction | ⌘K primary; keyboard reorder |
| Density | High-medium |
| Story | Operations / conflicts / publish integrity |
| Identity | Near-black panels, phosphor or single cold accent, mono metadata |

**Evidence:** Keyboard Shortcut Hint, Dark Theme, Monospace Accent, High Density (minority), Raycast/Superhuman/Linear tone  
**Prototype:** `concepts/d2-spec-instrument.html`

---

## D3 — Compose Pair
**Builder desk; canvas + inspector (Retool/code-panel lineage)**

| Axis | Choice |
|---|---|
| Nav | Top tools; modules dock; collections secondary |
| Hierarchy | Canvas center, inspector right |
| Interaction | Compose-first; live preview pair |
| Density | Medium |
| Story | Page as the product |
| Identity | Hard rules, bordered blocks, paired panes |

**Evidence:** Code Panel Pairing, Bordered Panels, Retool builder framing, Tabbed Content  
**Prototype:** `concepts/d3-compose-pair.html`

---

## D4 — Ledger Index
**Archive / register; top index + stamps**

| Axis | Choice |
|---|---|
| Nav | Top horizontal primary + collection index tiles |
| Hierarchy | Masthead → register table |
| Interaction | Record-oriented; status stamps |
| Density | Medium, high legibility |
| Story | Publication register / trust |
| Identity | Serif titles, cool paper, civic single accent |

**Evidence:** Top Horizontal Nav (translated), Pentagram/Sagmeister archive IA, Light Theme, Single Accent  
**Prototype:** `concepts/d4-ledger-index.html`

---

## D5 — Facet Desk
**Hugging Face / Cloudflare lineage — filterable catalogue instrument**

| Axis | Choice |
|---|---|
| Nav | Left facet rail for Content types + global search |
| Hierarchy | Filters → results → detail |
| Interaction | Filter-in-nav; suggestion chips on empty search |
| Density | Medium-high |
| Story | Find anything across typed collections |
| Identity | Facet chips, result rows, mono counts |

**Evidence:** Filter Field In Navigation (Cloudflare), Header Search, Keyboard Shortcut, Hugging Face faceted discovery, GitLab suggestion chips  
**Prototype:** `concepts/d5-facet-desk.html`
