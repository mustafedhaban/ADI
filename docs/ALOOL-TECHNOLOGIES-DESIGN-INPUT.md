## Design Exploration Brief

**Purpose:** Guide five meaningfully different homepage/company-site concepts for Alool Technologies.  
**Not yet:** Named concepts, mockups, color systems, or final direction.

### What every concept must include
- Clear company introduction space (even if copy is placeholder labeled as such)
- A services/capabilities region (structure only if catalog is UNKNOWN)
- An approach/process or “how we work” region
- A credibility / work / proof region (or explicit substitute-proof pattern)
- A primary conversion path
- Responsive first viewport + interior section logic
- Distinct art direction — not a recolor of another concept

### Dimensions the five concepts must vary

Concepts should differ across **multiple** of these axes (not color alone):

| Dimension | Spectrum to explore |
|---|---|
| **Brand positioning stance** | Restrained technology practice ↔ editorial authority ↔ creative-technology studio ↔ institutional professional services |
| **Visual tone** | Quiet/minimal ↔ premium dark ↔ light editorial ↔ corporate-clean |
| **Typography** | Technical mono+sans system ↔ editorial serif/sans pairing ↔ display-led hierarchy |
| **Layout density** | Sparse/breathing ↔ medium modular ↔ denser information-forward |
| **Presentation model** | Editorial storytelling-led ↔ product/capability-led ↔ process-led ↔ portfolio-led |
| **Narrative emphasis** | Technology/system clarity ↔ human-centered delivery story |
| **Character** | Corporate credibility ↔ creative craft (without tipping into avoid-styles) |
| **Motion intensity** | Near-static ↔ selective micro-interaction ↔ cinematic but restrained |
| **Image / art direction** | Typography-first / low imagery ↔ photographic realism ↔ abstract technical imagery ↔ work-screenshot led |
| **Navigation model** | Minimal few-link header ↔ section-anchored one-pager ↔ classic multi-page IA (Home / Work / Services / About / Contact) |
| **Conversion strategy** | Single dominant CTA ↔ soft inquire-after-proof ↔ multi-path contact |
| **ADI visibility** | ADI invisible / method-only ↔ ADI as named internal system ↔ ADI as visible capability (still subordinate to company brand) |

### Rules for meaningful difference
1. No two concepts may share the same combination of positioning stance + presentation model + navigation model.
2. Recoloring the same layout does not count as a new concept.
3. Each concept must state which research-collection lenses it draws from (e.g. consultancy IA, studio portfolio, product restraint, editorial type).
4. Each concept must note which **Open Questions** would most change it if answered differently.
5. Stay inside hard design constraints unless a concept is explicitly labeled as a controlled contrast study (and still avoid Playful / Colorful / Artistic / Brutalist / Futuristic as defaults).

## Evaluation Criteria

Score each concept **1–5** after concepts exist. Do not score yet.

| Criterion | Question | 1 = weak | 5 = strong |
|---|---|---|---|
| **Strategic fit** | Does it support the (known/assumed) website goal and business context without false business-model claims? | Misaligned or assumes unconfirmed model | Clearly supports confirmed intent; flexible to UNKNOWN services |
| **Brand fit** | Does it respect practice preferences and leave room for real brand assets once supplied? | Conflicts with constraints / invents identity | Credible provisional system; easy to swap real brand in |
| **Audience fit** | Would a cautious first-time visitor understand Alool and feel addressed? | Confusing or insider-only | Clear for undecided evaluators |
| **Differentiation** | Is it distinct from generic SaaS templates and decorative agency tropes? | Generic | Memorable within constraints |
| **Credibility** | Does it feel trustworthy for commissioning real work? | Gimmicky or hollow | Serious, proof-ready structure |
| **Clarity** | Is hierarchy, offer structure, and next step obvious? | Ambiguous | Scannable in one pass |
| **Visual quality** | Typography, composition, restraint, craft? | Weak / noisy | High craft, intentional |
| **Usability** | Navigation, reading, mobile, accessibility basics? | Friction-heavy | Easy, inclusive |
| **Scalability** | Can it grow to Services / Work / About / Contact / optional ADI page? | Homepage dead-end | System scales cleanly |
| **Conversion potential** | Does the conversion path feel natural and appropriately weighted? | Buried or aggressive without proof | Clear, timed after value |

### Comparison method (for later)
1. Score all five concepts independently on the ten criteria.
2. Note forced tradeoffs (e.g. editorial craft vs conversion directness).
3. Shortlist 1–2 concepts only after client intake reduces Open Questions.
4. Do not average away a fatal miss on Strategic fit, Clarity, or Credibility.
